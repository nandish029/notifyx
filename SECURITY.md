# Security Policy

## Supported Versions

Currently, only the latest major version receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

We take the security of NotifyX very seriously.

If you discover a security vulnerability within NotifyX, please send a direct message or email to the repository owner. All security vulnerabilities will be promptly addressed.

Please **do not** open public issues on GitHub for security vulnerabilities, as this could allow malicious actors to exploit them before a patch is released.

### What to include in your report
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact on end users (e.g., XSS in service worker, unhandled redirect).

We will try to acknowledge your report within 48 hours and provide an estimated timeline for the fix.
