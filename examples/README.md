# 🧪 NotifyX Examples

Welcome to the NotifyX playground! This directory is dedicated to community-contributed examples showing how to implement NotifyX in real-world scenarios.

## 🌟 Contributing an Example
Have you built something cool with NotifyX? We'd love to see it! 

**Ideas for examples:**
* **Vanilla JS:** A simple, single-page implementation.
* **AI Chatbot UI:** Showing a notification prompt after a long AI response.
* **Tailwind CSS:** A beautiful, styled notification toggle.
* **Dashboard:** Integrating notifications into a user settings panel.

## 🛑 Security Warning
When contributing examples:
1.  **NEVER** include your real `VAPID_PRIVATE_KEY`.
2.  **NEVER** include your real `VAPID_PUBLIC_KEY`.
3.  Use placeholders like `YOUR_VAPID_PUBLIC_KEY_HERE`.
